# Books to Scrape — Data Science Project (Phase 2)

**Dataset:** Books to Scrape (https://books.toscrape.com)
**Collection:** Web scraping — requests + BeautifulSoup (self-crawled)
**Records:** 1000 books | 50 categories
**Target:** `rating` (1–5) — Regression / `rating_class` (0/1) — Classification

## How to Run

```bash
pip install -r requirements.txt
python pipeline.py
```

Steps executed:
1. `import_to_db.py` — CSV → SQLite, prints 3 SQL query results
2. `load_data.py` — loads joined books+categories from DB
3. `preprocess.py` — EDA report + preprocessing
4. `feature_engineering.py` — TF-IDF + feature creation → final dataset

## EDA Key Findings

| Metric | Value |
|---|---|
| Records | 1000 |
| Missing values | 2 (description) → imputed with "" |
| Price range | £10.00 – £59.99 (mean £35.07) |
| Rating distribution | 1:226, 2:196, 3:203, 4:179, 5:196 (balanced) |
| Categories | 50 unique genres |
| Price–Rating correlation | r = 0.0282 (near zero — price doesn't predict rating) |
| Description length | 30–8646 chars (mean 1444) |

---

## Preprocessing Decisions

| Action | Justification |
|---|---|
| Drop `tax`, `num_reviews` | Zero variance (all 0) |
| Drop `price_excl_tax` | Perfectly correlated with `price_incl_tax` (tax=0 for all) |
| Drop metadata cols | `upc`, `image_url`, `page_url`, `crawled_at` — non-informative for modeling |
| Impute 2 missing descriptions | Replaced with empty string (minimal impact) |
| Label-encode `category` | 50 classes, integer encoding |
| MinMax scale `price`, `stock` | Required for distance-based models |
| Create `rating_class` | Binary target (≥3=1) for classification experiments |

## Feature Engineering Summary

| Feature Group | Count | Details |
|---|---|---|
| Numeric (original) | 2 | price_incl_tax, stock_count |
| Numeric (scaled) | 2 | price_incl_tax_scaled, stock_count_scaled |
| Numeric (new) | 6 | desc_length, desc_word_count, price_per_rating, stock_price_ratio, is_expensive, is_high_stock |
| Category encoded | 1 | category_encoded (LabelEncoder, 50 classes) |
| Price bucket (one-hot) | 4 | bucket_cheap/mid/expensive/premium |
| TF-IDF (description) | 100 | top 100 unigrams+bigrams, min_df=3, sublinear_tf |
| **Total features** | **115** | + rating + rating_class = **121 columns** |

**Modeling target:** `rating` (1–5) for regression, `rating_class` (0/1) for classification
